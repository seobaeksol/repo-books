# Apple Books형 UI 요구사항

## 공통 Shell

Repo Books는 기본적으로 ebook 앱처럼 보이고 동작해야 한다. 화면 상단은 앱 정체성과 로컬 모델 상태만 전달한다.

**상단에 남기는 요소**

- 앱명과 짧은 보조 라벨
- LM Studio 연결 상태

**상단에서 제거하는 요소**

- GitHub 주소 입력창
- 전역 화면 전환 탭
- 상단 `새 책` 버튼
- 책장 본문 안의 중복 생성 버튼

화면 이동은 데스크톱에서는 sidebar, 모바일과 태블릿 compact 화면에서는 bottom navigation과 sheet로 처리한다.

## 책장 화면: Desktop

데스크톱 책장은 Mac Books 앱과 유사하게 sidebar와 library grid를 사용한다.

```text
+----------------------+--------------------------------------------------+
| Repo Books            | Home                                             |
| LM Studio 상태         |                                                  |
|                      | 최근 읽은 책                                      |
| Library              | [wide book] [wide book] [wide book]              |
| - 홈                 |                                                  |
| - 최근 읽은 책        | [전체] [읽는 중] [생성 중] [초안]                 |
| - 내 책              |                                                  |
| - 컬렉션             | 내 책                                             |
| - 생성 중            | [cover] [cover] [cover] [cover]                  |
|                      |                                                  |
| + 새 책 만들기        |                                                  |
+----------------------+--------------------------------------------------+
```

**필수 요소**

- `최근 읽은 책` 가로 shelf
- `내 책` cover grid
- 컬렉션/상태 필터
- sidebar의 `새 책 만들기`
- 책 카드의 제목, 저장소명, 진행률, 상태 badge

책장 본문은 책을 고르는 공간이다. 저장소 입력, 생성 설명, 읽기 버튼을 본문 상단에 반복 노출하지 않는다.

## 책장 화면: iPad/iPhone

좁은 화면에서는 Home/Library 중심의 단일 컬럼을 사용한다.

```text
+------------------------------------+
| Repo Books              LM 상태     |
+------------------------------------+
| Home                               |
| 최근 읽은 책                        |
| [wide book]                        |
| [wide book]                        |
|                                    |
| [전체] [읽는 중] [생성 중] [초안]   |
|                                    |
| 내 책                               |
| [cover] [cover]                    |
| [cover] [cover]                    |
+------------------------------------+
| 책장           새 책           읽기  |
+------------------------------------+
```

**필수 요소**

- 하단 navigation: `책장`, `새 책`, `읽기`
- 최근 읽은 책은 세로 또는 가로 shelf로 표현
- 목차와 AI 패널은 bottom sheet로 표시
- 상단에는 생성 액션을 두지 않음

## 목차 생성 화면

목차 생성 화면은 저장소를 책으로 변환하는 작업 공간이다. 내부 입력 구조는 유지한다.

**상단 Toolbar**

- `책장으로 돌아가기`
- 화면 제목
- `읽기 시작`

**본문 영역**

- 저장소 URL 또는 경로 입력
- LM Studio 모델 설정
- 독자 수준과 생성 깊이
- 분석 진행 상태
- 생성된 Part/Chapter 목차 미리보기
- 생성 실패 시 재시도와 오류 상세

이 화면에서만 저장소 입력과 생성 설명을 노출한다.

## 읽기 화면

읽기 화면은 일반 ebook reader에 AI 여백 패널을 더한 구조다.

```text
+----------------+--------------------------------+----------------+
| 목차            | 책 본문                         | AI Tutor        |
| Part/Chapter    | Chapter page                    | 질문/답변       |
| 관련 파일        | 코드 앵커와 설명                 | 추천 질문       |
+----------------+--------------------------------+----------------+
| 이전 장   목차   보기 설정   AI 열기   다음 장                  |
+-----------------------------------------------------------------+
```

**좌측 목차**

- Part/Chapter 목록
- 현재 챕터 위치
- 관련 파일
- 챕터 진행률

**중앙 본문**

- 기술서적처럼 읽히는 챕터 본문
- 코드 앵커와 설명
- 체크포인트
- 다음 챕터 안내

**우측 AI Tutor**

- 현재 챕터 컨텍스트 기반 질문
- 본문 흐름 보조 설명
- 코드 앵커 기반 답변
- 추천 질문
- 응답 생성 상태와 재시도

**하단 Controls**

- 이전/다음 챕터
- 목차 열기
- AI 열기
- 포커스 모드
- 보기 설정

## 포커스 모드

포커스 모드는 책 본문 읽기를 우선한다.

- 목차와 AI 패널을 숨긴다.
- 중앙 본문 폭을 확장한다.
- 하단 controls는 최소 상태로 유지한다.
- `포커스 종료`, 현재 챕터 위치, 이전/다음 이동은 접근 가능해야 한다.

## 반응형 요구사항

- Desktop: sidebar + recent shelf + cover grid, reader 3열.
- Tablet compact: 단일 컬럼 책장, bottom navigation, reader sheet 패널.
- Phone: 단일 컬럼 책장, 하단 navigation 고정, 목차/AI는 bottom sheet.
- 긴 제목, 긴 저장소명, 코드 줄은 컨테이너를 깨지 않아야 한다.
- 주요 조작은 키보드와 스크린 리더에서 의미가 명확해야 한다.
