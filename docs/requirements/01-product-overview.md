# 제품 개요

## 배경

개발자가 새로운 GitHub 저장소를 이해하려면 README, 디렉토리 구조, 실행 경로, 주요 코드, 테스트 흐름을 오가며 읽어야 한다. Repo Books는 이 탐색 과정을 한 권의 기술서 또는 강의 교재처럼 재구성한다. 사용자는 저장소를 파일 탐색기처럼 훑는 대신 책장에 있는 repo book을 열고, 챕터 순서대로 읽으며 필요한 순간 AI에게 질문한다.

## 목표

- 사용자는 변환된 저장소 책을 Apple Books 같은 책장에서 찾고 다시 읽을 수 있다.
- 사용자는 새 저장소를 입력해 repo book을 생성할 수 있다.
- 생성된 책은 대단원, 소단원, section 본문 구조를 가지며 일반적인 기술서 또는 강의 흐름을 따른다.
- 각 챕터는 핵심 질문, 책임, 흐름, 설명 본문, 관련 코드 근거, evidence, glossary, recap, 체크포인트를 포함한다.
- 사용자는 읽는 중 우측 AI margin tutor 또는 모바일 sheet를 통해 현재 챕터 맥락으로 질문할 수 있다.
- 최근 읽은 책, 현재 챕터, 진행률, AI 대화 초안은 이어 읽기에 필요한 상태로 저장된다.

## 비목표

- MVP에서는 원격 GitHub 계정 인증, PR 작성, 이슈 관리 같은 GitHub 워크플로 기능을 제공하지 않는다.
- MVP에서는 저장소 코드를 자동 수정하거나 커밋하지 않는다.
- MVP에서는 책을 공동 편집하거나 다중 사용자가 같은 책장을 공유하지 않는다.
- MVP에서는 채팅이 주 학습 화면을 대체하지 않는다. AI는 책 읽기를 보조하는 창구다.

## 주요 사용자

- 처음 보는 코드베이스를 기술서처럼 읽고 싶은 개발자
- 팀 내부 저장소의 온보딩 자료를 자동으로 만들고 싶은 개발자
- 오픈소스 저장소를 챕터 단위로 체계적으로 학습하려는 학습자

## 핵심 용어

| 용어 | 정의 |
| --- | --- |
| Repo Book | 특정 저장소를 기반으로 생성된 ebook형 학습 자료 |
| 책장 | 최근 읽은 책, 내 책, 컬렉션, 생성 중 책을 보여주는 홈 화면 |
| 최근 읽은 책 | 마지막으로 열람한 순서로 정렬된 repo book 목록 |
| 책 생성 | 모델 준비, 저장소 분석, 대단원 설계, 소단원 설계, 근거 수집, 본문 생성, 챕터 수리, 책 일관성 점검을 거쳐 repo book을 만드는 장기 실행 작업 |
| 대단원 | 책의 상위 파트. 예: 저장소 지도, 화면과 상태, 유지보수자의 읽기 |
| 챕터 | 실제 읽기 단위. 본문, 관련 코드, 체크포인트, AI 맥락을 가진다 |
| AI Margin Tutor | 책을 읽는 동안 현재 챕터 옆에서 질문과 해설을 돕는 AI 패널 |
| 체크포인트 | 챕터를 덮기 전에 사용자가 확인해야 할 짧은 이해 확인 항목 |

## MVP 범위

- Apple Books형 책장 화면
- 최근 읽은 책과 내 책 grid
- 새 repo book 생성을 위한 책 생성 화면
- LM Studio 연결 상태와 생성 진행 단계 표시
- 대단원/챕터 목차와 5-8개 section 기반 본문 생성
- ebook형 읽기 화면
- 목차 패널, AI margin tutor, 관련 파일, 코드 근거 표시
- 모바일 하단 navigation과 목차/AI bottom sheet
- 로컬 우선 저장과 이어 읽기 상태 복원
