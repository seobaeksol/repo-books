# 사용자 흐름

## 1. 책장 열기

1. 사용자는 앱을 열면 책장 화면에 진입한다.
2. 데스크톱에서는 좌측 sidebar에서 홈, 최근 읽은 책, 내 책, 컬렉션, 생성 중 상태를 확인한다.
3. 모바일에서는 단일 컬럼 책장과 하단 navigation을 본다.
4. 시스템은 최근 읽은 책을 마지막 열람 순서로 표시한다.
5. 사용자는 책 표지 또는 최근 읽은 책 카드를 선택해 읽기 화면으로 이동한다.

## 2. 새 책 만들기

1. 사용자는 데스크톱 sidebar의 `새 책 만들기` 또는 모바일 하단 navigation의 `새 책`을 선택한다.
2. 시스템은 책 생성 화면으로 이동한다.
3. 사용자는 GitHub 저장소 URL, LM Studio 모델, 독자 수준, 책의 목적, 생성 깊이, 커스텀 프롬프트를 입력하거나 선택한다.
4. 시스템은 LM Studio 연결 상태와 선택 모델을 확인하고, 모델이 없으면 `lms get <model>`로 준비한 뒤 저장소 색인을 시작한다.
5. 생성기는 대단원 계획, 소단원 계획, 챕터 근거, section 본문, 챕터 수리, 책 일관성 점검을 순차 실행한다.
6. 사용자는 생성된 목차, 챕터별 진행 상태, 실패 챕터 재시도 여부를 확인한다.
7. 사용자는 `읽기 시작`으로 첫 챕터 또는 추천 챕터를 연다.

## 3. 책 이어 읽기

1. 사용자는 책장에서 최근 읽은 책을 선택한다.
2. 시스템은 마지막으로 열람한 챕터, 진행률, 목차 위치, AI 대화 초안을 복원한다.
3. 사용자는 책 본문을 이어 읽거나 목차에서 다른 챕터로 이동한다.
4. 읽기 위치와 챕터 진행률은 자동 저장된다.

## 4. 챕터 읽기

1. 사용자는 ebook형 읽기 화면에서 챕터 제목, 요약, 목표를 확인한다.
2. 중앙 본문은 기술서처럼 저장소 개념과 코드 흐름을 설명한다.
3. 관련 코드 블록은 설명의 근거로 필요한 시점에 표시된다.
4. 좌측 목차에서 대단원과 챕터 진행률을 확인한다.
5. 우측 AI margin tutor에서 관련 파일, 튜터 주석, 추천 질문을 확인한다.
6. 사용자는 하단 reading controls로 이전/다음 챕터, 포커스 모드, 목차, AI 패널을 조작한다.

## 5. AI에게 질문하기

1. 사용자는 읽기 화면의 AI margin tutor에 질문을 입력한다.
2. 시스템은 현재 책, 현재 챕터, 관련 파일, 이전 대화 맥락을 함께 전달한다.
3. AI는 현재 챕터를 기준으로 설명하고 필요한 경우 파일 경로나 코드 근거를 제시한다.
4. 질문 기록은 챕터 맥락에 저장된다.

## 6. 모바일 목차와 AI 패널

1. 모바일에서 읽기 화면은 단일 컬럼 본문을 우선한다.
2. 사용자는 하단 reading controls에서 목차 또는 AI 버튼을 선택한다.
3. 시스템은 하단 sheet로 목차 또는 AI 패널을 연다.
4. sheet를 닫으면 본문으로 돌아간다.

## 예외 흐름

| 상황 | 기대 동작 |
| --- | --- |
| 저장소 URL이 유효하지 않음 | 목차 생성을 막고 URL 확인 메시지를 표시한다. |
| 저장소 접근 권한이 없음 | 접근 불가 상태를 표시하고 다른 URL 입력을 요청한다. |
| LM Studio 연결 실패 | 연결 상태, 설정 위치, 재시도 액션을 표시한다. |
| 책 생성 실패 | 스캔 결과, 부분 목차, 단계별 artifact를 유지하고 재생성을 제공한다. |
| 일부 챕터 생성 실패 | 생성된 책을 보존하고 실패 챕터만 재시도할 수 있게 한다. |
| AI 응답 생성 실패 | 질문 입력을 보존하고 재시도할 수 있게 한다. |
| 저장 실패 | 저장 실패 상태를 표시하고 자동 재시도한다. |
