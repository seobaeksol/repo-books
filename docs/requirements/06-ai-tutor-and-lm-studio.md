# AI Tutor와 LM Studio 연동 요구사항

## AI의 역할

Repo Books의 AI는 저장소를 기술서적 형태로 변환하고, 사용자가 책을 읽는 동안 여백에서 질문에 답하는 튜터다.

AI가 수행하는 핵심 작업은 다음과 같다.

- 저장소 구조를 분석해 책 제목, Part, Chapter 목차를 만든다.
- 각 Chapter를 기술서적처럼 읽히는 본문으로 생성한다.
- 본문 설명과 관련 파일, 코드 앵커를 연결한다.
- 독자가 읽는 중 질문하면 현재 Chapter 컨텍스트를 우선해 답한다.
- 생성 실패 또는 컨텍스트 부족 상태를 명확히 알리고 재시도 가능한 정보를 제공한다.

## LM Studio 연동

**우선순위:** P0

- 시스템은 LM Studio의 로컬 모델 서버와 연동해야 한다.
- API Base URL은 설정 가능해야 한다.
- 모델 목록을 불러올 수 있으면 선택 UI를 제공한다.
- 모델 목록을 불러오지 못하면 모델 ID를 직접 입력할 수 있어야 한다.
- 연결 테스트 기능을 제공해야 한다.
- 책장 상단에는 연결 여부만 간결하게 표시한다.
- 모델명, 컨텍스트 길이, 파일 색인 상태 같은 세부 정보는 목차 생성 화면에서 표시한다.

**기본 설정 예시**

| 항목 | 값 |
| --- | --- |
| API Base URL | `http://localhost:1234/v1` |
| API 형식 | OpenAI 호환 Chat Completions 계층 |
| 인증 | 로컬 개발 기본값은 인증 없음 또는 더미 API Key 허용 |

## 저장소 분석 컨텍스트

AI는 저장소 전체를 한 번에 모델에 넣지 않고 단계별 컨텍스트를 구성한다.

- 디렉토리 트리
- 패키지/빌드 설정 파일
- README와 문서 파일
- 엔트리 포인트
- 주요 모듈과 파일
- 테스트 파일
- 현재 Chapter와 관련된 파일
- 이전 Chapter에서 만든 요약

## 컨텍스트 선택 원칙

- 책 전체 목차 생성에는 저장소 구조, README, 설정 파일, 엔트리 포인트를 우선한다.
- Chapter 본문 생성에는 해당 Chapter의 목표와 직접 연결되는 파일을 우선한다.
- 큰 파일은 요약 또는 필요한 부분만 포함한다.
- 코드 근거가 필요한 답변에는 파일 경로와 심볼명을 포함한다.
- 모델 컨텍스트 한계를 초과하지 않도록 청크와 요약을 사용한다.
- 저장소에 없는 내용을 확정적으로 말하지 않는다.

## 책 목차 생성 프롬프트 요구사항

목차 생성 시 AI는 다음 입력을 받아야 한다.

- 저장소 URL 또는 경로
- 저장소 구조 요약
- 주요 파일 요약
- README와 문서 요약
- 사용자의 독자 수준
- 원하는 생성 깊이
- 선택한 LM Studio 모델
- 모델 컨텍스트 한계

출력은 구조화된 데이터로 받아야 한다.

**권장 출력 필드**

| 필드 | 설명 |
| --- | --- |
| bookTitle | 책 제목 |
| subtitle | 짧은 부제 |
| overview | 책 전체 요약 |
| audience | 예상 독자 |
| parts | Part 목록 |
| chapters | Chapter 목록 |
| objectives | 각 Chapter의 읽기 목표 |
| relatedFiles | 관련 파일 목록 |
| codeAnchors | 본문과 연결할 코드 근거 |
| checkpoints | 이해 확인 체크포인트 |
| estimatedMinutes | 예상 읽기 시간 |

## Chapter 생성 요구사항

Chapter 생성 시 AI는 다음을 제공해야 한다.

- Chapter 목표
- 저장소에서 이 Chapter가 필요한 이유
- 관련 파일과 코드 앵커
- 기술서적처럼 이어지는 설명 본문
- 실행 흐름 또는 데이터 흐름
- 독자가 놓치기 쉬운 설계 포인트
- 체크포인트
- 다음 Chapter로 이어지는 짧은 연결 문장

본문은 단순한 파일 요약이 아니라 독자가 이해할 순서로 재구성해야 한다.

## AI Tutor 패널 요구사항

AI Tutor는 읽기 화면의 여백 또는 bottom sheet에서 동작한다.

- 현재 책, Part, Chapter, 선택한 코드 앵커를 기본 컨텍스트로 사용한다.
- 답변은 책 본문을 대체하지 않고 읽기를 보조한다.
- 사용자가 일반 개념을 질문하면 현재 저장소와 연결해 설명한다.
- 필요한 경우 관련 파일 경로와 심볼명을 포함한다.
- 답변 생성 중 상태를 표시하고 실패 시 재시도를 제공한다.
- 추천 질문은 현재 Chapter를 더 잘 읽기 위한 질문이어야 한다.

## 생성 실패와 재시도

| 상황 | 처리 |
| --- | --- |
| LM Studio 연결 실패 | 책장에는 연결 실패 상태, 목차 생성 화면에는 설정 확인과 재시도 제공 |
| 모델 응답 실패 | 분석 결과를 유지하고 같은 입력으로 재생성 가능 |
| 컨텍스트 초과 | 파일 범위를 줄이거나 요약 후 재시도 |
| 불완전한 JSON | 원문 응답을 보존하고 구조화 재시도 |
| 일부 Chapter 생성 실패 | 생성된 Part/Chapter는 유지하고 실패 Chapter만 재시도 |

## 품질 가드레일

- AI는 저장소 내용을 조작하지 않는다.
- AI는 읽지 못한 파일이나 근거가 부족한 내용을 단정하지 않는다.
- AI는 책의 흐름을 우선하고, 채팅 중심 제품처럼 과도하게 대화를 유도하지 않는다.
- AI는 코드 앵커가 없는 설명을 일반론처럼 표시하지 않는다.
- AI는 독자의 수준에 맞추되 중요한 설계 흐름을 생략하지 않는다.
